Use it like an app

On a phone, open this page and choose “Add to Home Screen” from the browser's share or menu button. lanledger then opens full-screen from its own icon.

How to read this page
  • Before a device can reach a site it asks for the site's address. That question is a lookup. lanledger counts lookups, so it knows which sites a device contacted and roughly how often. It cannot see pages, messages, or how much data moved.
  • A device name marked guess was worked out from what the device looks up. Give the device a name to replace the guess.
  • Devices using a VPN, iCloud Private Relay or their own private DNS show little or nothing here. lanledger flags them when it can tell.
  • With more than one Deco unit, each device shows which unit it connects through. That is usually the nearest one, so it hints at where the device is. Type a unit's name in the search box to see everything on it.
  • With a Deco connected (Settings), devices take the names from the Deco app, and lanledger estimates how much data each one moved from the speeds the Deco reports.
  • Blocking a site makes its lookups fail for the whole network. It can take a few minutes to kick in, and it cannot block a single device.
